Mes classes

Un seul import Pronote par an, puis un fichier que toutes tes applis prof savent lire.

📖 Mode d’emploi : début d’année, élève qui arrive, élève qui part

⬇︎ Télécharger le mode d’emploi (PDF)

A En début d’année : une seule fois

  1. Dans Pronote : Ressources → Élèves, puis choisis la classe (ex. 2de 8). Copie la liste et colle-la dans Excel, puis enregistre-la en .xlsx (ex. Seconde_8.xlsx). Recommence pour chaque classe. Ce chemin donne la colonne Sexe, indispensable pour les barèmes filles/garçons, et la colonne Classe : le nom de la classe dans les applis est celui de Pronote (ex. 2GT08), pas le nom du fichier. Si un « prénom d’usage » est rempli, c’est lui qui est gardé. Autre possibilité : un seul classeur Excel avec un onglet par classe.
  2. Portail mon-EPS → Coordo & évaluation → Classes et notes → « Mes classes ». « Choisir les fichiers » : sélectionne tes 8 fichiers d’un coup (un par classe). Vérifie le tableau : chaque classe, son nombre d’élèves, filles et garçons.
  3. « Télécharger « Mes classes » » : tu obtiens mes-classes-2026-2027.csv. Il ne garde que la classe, le nom, le prénom et le sexe.
  4. Range ce fichier dans ton Nuage apps.education, et nulle part ailleurs : pas de mail perso, pas de Drive ni de clé perso. Sur l’iPad, il doit être accessible depuis l’app Fichiers (app Nuage ou « Sur mon iPad »).
  5. Dans chaque appli prof : « Choisir le fichier Pronote » → ce fichier. Toutes les classes arrivent d’un coup.

Nouvelle année ? Si l’appli affiche « Archiver l’année et repartir à zéro », fais-le avant d’importer les nouvelles classes : la sauvegarde est téléchargée (protège-la par un mot de passe), puis l’appli est vidée.

B Un élève arrive en cours d’année

  1. Dans l’appli prof, onglet Classes (gym : Réglages) : écris le nom de la classe exactement comme dans l’appli (ex. 2GT08).
  2. Dans « Ou coller la liste », écris l’élève : NOM Prénom (ex. DUPONT Marie). Plusieurs élèves : un par ligne.
  3. « Importer la liste collée » → l’appli voit que la classe existe déjà → touche « Ajouter ces élèves ». Un message confirme : « 2GT08 : +1 (Marie DUPONT) → 36 élèves ».
  4. Refais scanner le QR de démarrage de cette classe aux groupes, sinon le nouvel élève n’apparaît pas sur les tablettes.
  5. Recommence dans chaque appli qui suit cette classe.

C Un élève quitte la classe, ou beaucoup de changements

  1. Réexporte la classe complète depuis Pronote.
  2. Importe ce fichier dans l’appli → « Remplacer la liste ». Un élève absent du nouveau fichier garde ses résultats, mais apparaît « Hors liste ».
  3. Refais scanner le QR de démarrage.

! Les pièges

  • Ne touche jamais « Remplacer la liste » après avoir collé un seul nom : la classe ne contiendrait plus que cet élève. Pour un ajout : toujours « Ajouter ces élèves ».
  • Le nom de la classe doit être identique : « 2GT08 » et « 2GT8 » font deux classes différentes.
  • « Annuler » ne change rien : en cas de doute, annule.

✓ En fin d’année

  • Notes : portail → « Relevé de notes » → reporte-les dans Pronote.
  • Puis supprime le fichier « Mes classes » de ton Nuage.

1 · Lire les exports Pronote

Pronote : liste des élèves de la classe → Exporter (xlsx, xls ou csv). Tu peux choisir plusieurs fichiers d’un coup ; avec une colonne « Classe », un seul fichier suffit pour toutes tes classes.

3 · Enregistrer le fichier

Le fichier ne garde que la classe, le nom, le prénom et le sexe. Rien d’autre de l’export Pronote (date de naissance, numéro, adresse, régime…) n’est conservé.

Ce fichier contient des noms d’élèves. Range-le uniquement dans ton Nuage apps.education : pas en pièce jointe d’un mail personnel, pas dans un Drive ou une clé personnels. Supprime-le en fin d’année, une fois les notes reportées dans Pronote.

4 · L’importer dans chaque appli prof

Dans chaque appli prof : onglet Classes (gymnastique : onglet Réglages) → « Choisir le fichier Pronote » → ce fichier. Toutes les classes arrivent d’un coup. À faire une fois par appli et par an. Élève arrivé en cours d’année : voir le mode d’emploi, partie B.

Confidentialité

Cette page ne garde rien et n’envoie rien sur internet : les fichiers sont lus sur ton appareil, et tout disparaît quand tu fermes la page. Elle fonctionne aussi sans connexion après une première ouverture.
